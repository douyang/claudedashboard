Posting from another Claude session

Every Claude session that works on a project reports here through this artifact's database. The claude-dashboard skill holds the full procedure. Reuse a document id to update a record in place.

projects/<slug>: one document per project. Fields: name, aliases (other names that job rows use), where (cloud or local; derived when absent), surface, sessions (session ids), repos, artifacts, status (active, paused or done), pinned, note, lastActivityAt (set on each report; it keeps the project active for 72 h).

sessions/<session id>: one document per session, rewritten as it runs. Fields: title, project, where, surface, status, createdAt, updatedAt, tok (input, cache reads, cache writes and output together), out, usd, src, and partial when the figure is a floor. When the Claude Code Remote connector answers, the board reads cloud sessions live and those figures replace the stored ones.

ticks/<session id>~<15-min bucket>: a usage snapshot. Fields: sid, project, at, tok, out, usd, src. Velocity and the chart come from these snapshots. This page also writes one when it reads a changed live total.

jobs: project, group
The project and a sub-heading inside it.
label, note
What the job is, in one line, and the latest detail.
surface
Where it runs: Claude Code · web (cloud), Claude Code · CLI or Cowork (local).
status
queued, running, waiting (needs a person), done, failed or stopped.
blocked
What the job waits on.
total, done, unit
Progress, for example 4320 of frames.
rate, estSec
Units per second, and the expected length in seconds.
order, due, link
Sort key, a deadline as 2026-10-15, and an https address.
askedAt, answeredAt, answer
A question to a person, when they answered, and what they decided.
queuedAt
When the job joined the queue.
tok, tokOut, tokEst
Tokens used so far, the output tokens among them, and the expected total.
startedAt, updatedAt, finishedAt
Timestamps in UTC, as 2026-10-01T06:21:41Z. A running job with no report for 30 minutes is stale.

meta/board holds a note and updatedAt. meta/quota holds the account limit as Claude Code reports it: status (allowed, allowed_warning or rejected), type (for example five_hour), resetsAt, overage, notice, updatedAt. Optionally pct (the share of the current window used, 0 to 100), limitTok (the window's token cap when a session knows it), weekResetsAt and weekPct for the 7-day window. The window tiles use each one when it is posted and say so while it is missing; they never guess a cap.

A project is active when it has an open job, a running session, or any report in the last 72 hours. A project marked paused or done is inactive; a pinned project stays active. Token figures count every token the model reads or writes, cached context included; most are cache reads, which cost about a tenth of new input. Cost is at API list prices, as Claude Code reports it. Cloud sessions are read live from the Claude Code Remote connector every 10 minutes. Cowork and local CLI sessions appear only when they report, and a report marked partial is a floor. Velocity divides the tokens between two snapshots evenly over the time between them. Times are in your clock.
